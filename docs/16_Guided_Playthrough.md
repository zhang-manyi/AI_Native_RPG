# 引导式调查：执行约定与验收路线

本文件记录当前 Web 版本的执行约定，优先于 13–15 中尚未落地的长流程设想。
目标是让玩家不输入自由文本，也能完成调查；自由输入仍用于追问、角色交流和记忆交互。

## 台词与决策

| 内容 | 执行方式 | 模型调用 |
|---|---|---|
| 进入场景的固定对白 | `presentation` 按 `speaker` 播放，点击或空格继续 | 0 |
| 环境流言、过渡线索 | `delivery: narration`，自动结算唯一结果并播放 | 0 |
| 关键选择 | `delivery: choice`，先检定、应用结果，再演绎 | 点击通常 1 次；观察为 0 |
| 选择处自由输入 | 先分类到可见选项；匹配后同一套检定，再演绎 | NPC 交谈 2 次；观察和固定结论只需分类 1 次 |
| 不匹配任何选项的交谈 | 当前 NPC 的完整 Harness，包括 Memory、Tools 和反思 | 按工具调用次数变化 |

普通交谈不消耗关键选择的交换次数，也不替玩家选择默认结果。
在没有 NPC 的地点，自由聊天不可用；调查选项与旁白仍可使用。

`presentation` 的说话者为 `player`、`narrator` 或具体 NPC id。它不会自动提交到
`/turn`，因此固定对白不会隐式调用 NPC。这里的“自动”指不要求输入或决策；玩家仍掌握
阅读速度，通过点击或空格翻到下一句。

自动事件会登记信息、揭露对应线索。关系变化来自明确的事件后果或玩家主动自由交谈中的
有效行动：M6 警告转述会按剧本增加玛尔塔 fear 12，只结算一次，不因重复播放而增加。
已观察的同一物证选项不再出现，防止重复刷调查进度。

旧 `delivery: dialogue` / `scripted_lines` 格式保留给旧剧本；村庄剧本使用新的呈现方式。
整个新剧本的衔接按 YAML 顺序与前置条件确定，不再用算子冷却阻挡必需的下一组选择。
算子仍是可观测标签。新自动事件不需要生成额外的“铺垫”来启动下一轮聊天。

## 地点与人员

| 地点 | 在场 NPC | 内容 |
|---|---|---|
| 玛尔塔的家 | 玛尔塔 `npc_a` | M1、S1、M2、F1、M3；高风险回访时的 M6 警告转述 |
| 村庄广场 | 无具名对话 NPC | F2；通往其他地点 |
| 酒馆 | 老板 `npc_c` | M4；若尚未听过，F2 |
| 森林入口 | 洛伦 `npc_b` | M5 现场观察；M6 持续施压 |
| 任意地点 | 无报告对话对象 | M7 向镇上议事厅提交调查报告 |

广场上的流言是环境声音，不需要为路人建立一个可自由对话的 NPC runtime。
洛伦在当前版本固定在森林入口，不实现日程移动或跟随。

`locations` 限制事件地点；有 `npc_id` 的事件还要求对应 NPC 活着且在场。
“曾经去过”只是一项历史条件，不能代替“现在在这里”。移动批准后结束之前的事件，
不领取其默认结果；单次事件会记为已结束。拒绝的移动不影响事件。
存档恢复时也会清理不在当前位置的旧活动事件。

M7 是 `manual_only`：完成或离开当前对话后，在任何地点通过“整理调查报告”打开。
镇上议事厅是委托方；报告不绑定现场 NPC，也不会触发他们的回应或写入他们的记忆。
五种最终判断始终并列：洛伦涉案、老板涉案、玛尔塔涉案、艾拉自行离村、证据不足。
提交前再次确认会结束本次调查。“暂不提交，合上报告继续调查”免费退出，不提供答案提示。

## 可直接点击走通的真相路线

全程不用自由输入，也不用修改调试面板中的数值。

1. 阅读开场，在 M1 选择“我不是来添麻烦的”：玛尔塔 trust 10 → 13。
2. 在 S1 选择帮忙修门闩：trust 13 → 28，fear -5。
3. 在 M2 选择“你不用一个人扛着”：trust 28 → 40。
4. 自动播放 F1：玛尔塔提到艾拉的外衣、钱、母亲的木梳不在了。
5. 在 M3 选择“你说了我才帮得上”：取得目击信息，调查 stage 0 → 1。
6. 去广场，自动听到 F2：艾拉曾打听通往镇上的路和出村车辆。
7. 去酒馆，在 M4 选择“先来一杯，你这儿人不少”：取得时间线，stage 1 → 2。
8. 自动播放 F3：老板对钟点记不准，但提供了先后顺序和后来送货人的见闻。
9. 经广场去森林入口；遇到一天的收束，阅读后点击“睡下，等天亮”。
10. 在 M5 依次观察足迹、布片、血迹。足迹推进一次 stage，重复观察不会刷进度。
11. 点击“整理调查报告”，选择“我认为艾拉自行离村，可能仍然活着”，确认提交，阅读报告结局。

当前时间成本来自移动，一次移动一时段，过夜整理不收费。上述路线移动四次，
会跨过一次过夜整理；自动台词和同一次到访中的选择不额外耗时段。
阅读与模型响应速度影响实际分钟数，不能用时段数推算真实游玩耗时。

## 分支与结局

| 结果 | 当前条件与行为 |
|---|---|
| 有证据支持的去向判断 | F1/F2/F3 均已揭露、观察过森林足迹，提交自行离村判断后进入 `truth_uncovered` |
| 尚待核实的去向判断 | 同一选项可提前选择；记录不足时进入 `report_unverified`，不把猜测变成新事实 |
| 涉案判断 | 可选择洛伦、老板或玛尔塔，记录报告对象并结束；没有现场认罪或系统纠错 |
| 无定论报告 | 明确提交证据不足的报告后进入 `report_unresolved`，结束本次调查 |
| 洛伦先动手 | M6 警告已披露，仍继续施压使 tension 达到 0.8，显示“调查失控” |
| 超时 | 四天共十二个移动时段用尽，进入第五天且真相仍未揭露，调查结束 |
| 暂不下结论 | 不结束调查，允许继续移动与交谈 |

M1/M2 的追问、试探可能失败，玛尔塔退缩或增加恐惧；M3 的失败可以关闭她的目击线。
如果已取得 F1，玩家仍可通过酒馆时间线和森林观察取得 F3，推导真相，
不再依赖把玛尔塔的 trust 补到 40。森林观察不要求先完成社交线。
选项不随隐藏证据解锁；证据决定报告的支撑程度，而非决定玩家能提出哪种猜测。
提交报告不会揭露 `ella_whereabouts` 或 `loren_that_night` 中的私密经过。
`tell_loren_alive` / `told_loren_truth` 仅保留为旧选项/结果 ID；新结果写入 `report_departure`，
不再写入旧口供标记 `told_loren_truth`。已结束的旧存档保留结局，报告中途存档恢复时使用新脚本。

NPC 的错误信念不等于世界真相。洛伦的私密记忆仍保留误以为害死艾拉的设定；报告流程不会让他认罪。
玩家结局界面使用独立的 `player_title` / `player_text`，不会把内部
`accused_the_wrong_man` 或“指控错人”的调试标签直接展示成系统裁判。

M6 采用玩家不在场、玛尔塔事后转述的最小分支；不模拟洛伦的移动，也不实现现场多 NPC 对峙。
S2 喝酒混熟、S3 广场调查支线不属于当前可玩范围。
S1 已实现修门闩这一项具体行动；“承诺保密后再背诺”的后续关系链未实现。
`marta_clams_up` 保留为非终局里程碑，不能把它列为一条已经验收的独立结局。

## 可直接点击走通的“调查失控”路线

1. 普通新开局，从玛尔塔家经广场到森林入口，不必先完成社交调查。
2. 在 M5 选择追问洛伦“你那晚在这里做什么”：初始 trust 0，必定失败，关闭 M5，tension 到 0.2。
3. 在 M6 两次选择“继续逼问洛伦”：tension 依次到 0.4、0.6。继续施压的选项暂时隐藏，需先核实警告。
4. 经广场回玛尔塔家；遇到收束先过夜。自动听取 M6 转述，fear +12，警觉与威胁两条事实被记录。
5. 经广场再去森林，收束后过夜，选择“继续逼问洛伦”：tension 到 0.8，出现“调查失控”终局。

共六次移动，在第三天上午完成；选择不额外扣时段。单纯夜间旅行不加风险，必须主动施压。
每次施压增加 0.2，听警告不自动增加张力。也可以选择“停止施压，靠线索作判断”，永久关闭
这个施压事件，调查仍可继续；如果已取得真相所需证据，仍可打开 M7 得到真相结局。
玛尔塔的转述只说她经历的警告，不会告诉玩家洛伦以为自己害死艾拉。

## 执行与恢复

选项 id 必须属于当前可见选项。过期、伪造或未解锁的 id 会被拒绝，不消耗选择。
自由输入分类器只收到可见选项的 id 和文本，不看到结果或检定阈值，也不能调用工具。
选择结算后，NPC 表达调用只返回台词，没有二次修改状态的工具权限。
普通自由交谈继续使用完整 Harness。

`npc_reply` 是固定回复，也是模型表达失败的兜底。Mock 模式直接播放它；真实后端
以结果和固定回复约束演绎。超时不会撤销结果或让玩家再掷一次检定。
自然语言与结果的一致性仍需要真实模型评测；单元测试验证调用顺序和权限边界。

叙事 trace 的 `authored_events` 记录一次推进中所有自动事件，`resolutions` 记录
选项、检定档位、结果和 proposal 判定。旁白与关键选项的模型调用成本应分开查看。
公开 `scene.ready` 通知客户端本轮完成，因此隐藏开发者面板也能正确恢复操作。

每个 NPC 独立保存 `memory_{npc_id}.json`。`session.json.npc_id` 为存档时当前位置
的 NPC，空场景为 null；它不决定后续对话路由。旧单记忆文件存档继续加载该 NPC
的记忆，其余 NPC 使用 seed。固定 NPC 对白和选项交互同样记入该 NPC 的记忆。
恢复旧存档不重置人物关系、线索、已完成事件或终局；不保证旧存档拥有新版本开局路线。

## 验收

`tests/test_web_playthrough.py` 从真实 Session 开局，使用页面提供的选项和可达地点，
验证真相、指认、洛伦先动手、超时、保存恢复、观察去重、地点隔离，以及先结算后生成。
新增危险路线还验证警告后停止施压能保留真相路线、警告只生效一次，以及终局存读档。
这些完整路线不直接写 trust/stage/flags。

`tests/web_frontend.test.cjs` 执行真实 app.js 的状态逻辑，验证固定台词不提交请求、
无 NPC 调查、公开完成信号、终局控制和重复快照。它不替代视觉试玩。

```powershell
uv run pytest tests/ -x
node --test tests/web_frontend.test.cjs
uv run python scripts/web.py --mock
```
