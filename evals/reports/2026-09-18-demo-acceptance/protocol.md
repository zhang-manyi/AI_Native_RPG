# 真实完整演示验收协议（运行前固定）

基于普通开局和 docs/16 的真相路线。只由玩家 HTTP 接口推进，FastAPI TestClient
驱动实际 Session、Harness 和真实模型网络请求，不启动 GUI。观察器只读内部状态、
记录网络、重定向存档/Trace目录；不设置关系、事件、标记或模型结果。

## 路线与检查点

执行输入见 route.json（不包含答案/评分标签）。

1. 开局尝试从玛尔塔家直接去不相邻的森林：实际 Validator 拒绝，位置与时间不变。
2. M1善意、S1修门闩、M2善意、F1自动证据、M3善意：自然生成回应不得提前
   透露艾拉去向、洛伦私密经过；检查台词和裁决、状态一致。
3. 真实告诉玛尔塔笔记本名字；保存并关闭会话，通过 resume_from 恢复，然后追问原话。
   不能注入脚本 NPC 历史；记忆答错作为已知质量限制，严重剧情泄露则阻塞演示。
4. 广场F2、酒馆M4善意/F3；自然追问已公开时间线。不要求模型查工具或提议行动。
5. 经广场完成过夜，森林观察足迹/布片/血迹；整理报告并提交自行离村判断。
6. 到 truth_uncovered 后再次存读档，并确认结束后的输入被拒绝。

成功标准：全程真实后端，模型表达不能以 authored fallback 冒充成功；所有玩家步骤、
请求响应、工具、裁决、状态和成本均可核对；取得F1/F2/F3/足迹后到目标终局；恢复保持
状态和记忆且可继续；拒绝动作未虚报成功。助手逐条复核全部台词和玩家可见提示，
明确严重泄露、虚构成功、推进提示缺失与一般编造的区别。规则达到终局不等于语义验收。

## 预算与配置

使用当前 .env / 环境解析出的供应商、模型和端点，密钥不落盘；真实配置缺失即停止。
默认温度、工具循环、策略、检索器按实际Web装配；三个表达候选维持False。
每次完整运行最多50次HTTP尝试、180,000 token、600秒；每次输出上限1200 token，
客户端默认30秒超时/最多3次网络尝试/一次重解析也计入。请求前使用UTF-8字节数加
输出上限及512预留检查token预算，有usage后换成实耗，无usage保留预留。每请求
最大预留40,000；时间上限在下次请求/玩家操作前检查，正在执行的请求可能有超时尾部。
不核实费率则金额null。全轮最多三次有效完整运行（初验+最多两轮修复验证），
总150请求/540,000 token/1800秒；基础设施沙箱失败允许一次授权后重跑，另行计账。
不因措辞或普通记忆答案失败反复采样。预算用尽保存成果并报告未完成。

## 修复约束及预留变体

最多两轮，只修已定位严重阻塞。若需改变模型输入/表达，修复前冻结未运行变体：
同一普通开局，用玩家自己的布袋名“河岸”替换笔记本；恢复后问布袋名；酒馆问
“你说的送货人是在关门前还是关门后看见她的？”；其余玩家操作相同。
这些是新输入组合，不是独立故事，不声称广泛泛化。若变体也用于调优则不再作为留出。
未发生表达修复时不为凑样本运行变体。保留所有失败、历史报告与既有改动，不commit/push。
