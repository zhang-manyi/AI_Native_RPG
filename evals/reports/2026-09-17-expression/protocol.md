# 表达证据实验：预先固定的约定

在候选实现和真实生成前固定 `evals/expression_holdout.json`。7 个合成案例覆盖普通回述、同义追问、公开事实、两名 NPC 的私密追问、披露拒绝及移动拒绝后的普通回答。标签不进入模型请求，不扩展可玩剧情。

开发数据保留 2026-09-17-memory 的全部失败。局部开发对照沿用旧报告 repeat=1、lag=0、发生重写的全部四条输入，加上两个私密控制；不按输出好坏选择。上游检索、工具结果、计划、裁决固定。候选只改变表达输入投影；旧记忆的来源只能通过评测保存的原始玩家输入和 written_ids 验证补充，运行时不猜测旧记忆来源。

候选冻结后，先在全部新案例做固定输入对照，再在全部新案例运行完整 Harness.respond。完整路径不强塞 fixed_action：该字段仅用于局部拒绝控制；完整模型没有提出行动时，记录拒绝路径未覆盖，不能算作拒绝测试通过。每个阶段、案例、条件重复三次，基线和候选轮换先后。检索固定 Hashing(64)、top_k=3；不同时调检索器。

局部开发最多 48 HTTP 请求/150000 已知 token/600 秒；留出局部最多 56 请求/150000 token/600 秒；完整留出最多 180 请求/450000 token/1200 秒。每请求至多600输出 token，25秒超时，无传输重试；预算在请求前检查，允许最后一次在途请求超出累计 token/时间上限。失败、重解析和未完成均保留，不补跑成功样本替换。

记录字面答案、证据进入上下文、事实依据、披露违规、裁决与状态、完成率、延迟、HTTP请求与token。货币成本在无经核实费率时记为未知。字面筛查不等于语义判分，所有完整输出由 Codex 助手复核，明确不是独立人工标注或校准 Judge。

预先采用门槛：开发及留出均有普通回答收益；所有留出完成；无确认私密披露或错误宣称行动成功；事实依据不回退；完整平均 token/延迟不得超过基线两倍。案例量很小，即使通过也只支持本分布；任何门槛失败、关键路径未覆盖或证据不足均保留默认基线。不得用留出结果调候选再报同一留出成绩。
