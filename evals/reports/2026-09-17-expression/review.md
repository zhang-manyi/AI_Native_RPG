# 受限表达证据：实现、结果与不推广决定

实现了默认关闭的 `Harness(filtered_dialogue_evidence=True)` 候选。它修复了本组输入中“已经取得的普通证据未进入最终回答”的主要通路，但没有达到预先固定的推广条件：完整留出仍有规划截断、无依据陈述和拒绝路径覆盖不足。因此游戏保留基线；`retain_dialogue_evidence` 和新开关均默认 `False`。不把保留基线解释为基线已经安全，基线本轮也出现私密披露。

## 实际实现与边界

- EpisodicMemory 新增可选 `source_player_id` / `player_statement`。Harness 从真实输入写入，截断规则与旧反思一致；只回述同一玩家的原话，不复制拼接的 NPC 回答。旧存档字段缺失时仍能加载，但不推断披露许可。无来源的旧记忆和 semantic belief 继续只参与私有规划。
- query_memory 保留原文本字段，增加执行结果的 ID。表达组装只用成功工具调用中的 ID 回查本 NPC 当前存储，不信任工具原文或模型自报许可；自动召回与工具补召回都能进入证据组装。
- 公开事实重新读取 Manager.player_view，使用裁决后的真实状态；partial 只传投影值。原始计划、策略、私有背景/目标、拒绝理由和工具返回不进入候选表达请求。身份来自 NPCWorldState 的公开姓名/介绍，性格数值只用于语气。
- 行动照旧走 Manager.submit / Validator。表达收到 none/applied/rejected/resolved 的结构化结果，不能由模型声明解除限制。世界写入路径没有增加。
- 无行动路径也独立生成表达，因此不能从 PlanningOutput.dialogue 绕过投影；已结算 authored outcome 走受限输入后演绎。原始剧情 hook 未被证明可公开，候选不透传它，可能影响叙事表现；本轮没有验收整段剧情体验。
- 不建设通用权限表。没有为每条私有记忆补造 fact 映射；已解锁事实从世界投影取得，无映射的主观经历保守不直传。公开事实当前传整个小型 PlayerView，未做相关性裁剪；大世界规模未验证。

来源字段不表示玩家说的内容是真实世界事实，也不授予修改世界或披露他人认知的权限。表达提示要求注明“你说过”。这仍是生成约束，不能保证模型不凭空编造；本轮观测到的虚构和否认正说明这一点。

## 固定实验与原始证据

[protocol.md](protocol.md) 与 [留出文件](../../expression_holdout.json) 在候选实现及真实生成前固定，哈希为 `ee3eab4e58304b2bca341e4d4e869a50e4376d55d4681140a82c497b8838862c`。7 个新案例包含普通回述、同义追问、公开姓名、两类私密追问及两类行动拒绝。标签没有进入被测模型；请求中的事实/记忆来自输入夹具而非标准答案。

先用旧报告全部 repeat=1、lag=0、重写路径的四条输入和两个私密控制做开发局部对照；旧基线请求逐字复核。旧玩家来源通过原始 tell、written_ids 和完整反思文本比对做评测内补充，不把这项迁移引入运行时。旧工具文本通过已记录存储做 ID 对照，未重新检索或改变当时的计划/裁决。开发之后 [selection.md](selection.md) 冻结候选，再依次运行新留出局部和完整 Harness，不据留出调整候选。

每个条件重复三次、temperature=0，固定 Hashing(64)、top_k=3；不是另一轮检索器选型。完整路径用相同 authored 输入前缀，经真实 Harness 写入规则构造记忆，再真实执行规划、工具、裁决、表达、反思；前缀不是新增真实模型对话。不同调用有独立世界/记忆实例，时间戳和记忆创建时间可能不同，文本和初始状态相同；没有跨条件刷新记忆。

原始记录：

- [dev/report.json](dev/report.json)：沙箱限制导致 36 次 ConnectError，全部保留，缺 usage，非模型效果。
- [dev-authorized/report.json](dev-authorized/report.json)：获网络授权后的整组开发对照，36/36 完成。
- [holdout-local/report.json](holdout-local/report.json)：固定上游的新留出对照，42/42 完成。
- [holdout-full/report.json](holdout-full/report.json)：完整 Harness 新留出，39/42 完成。

每个目录有 `wire.json`，含实际请求 body、所有 HTTP 返回/重解析、usage、finish_reason 与延迟，不存 URL/请求头/凭据。`sources/` 保存当次脏工作区源文件，manifest 保存哈希及环境；只记录 git HEAD 不足以复现这次未提交状态。旧报告均未改写。

真实请求模型 `deepseek-v4-flash`，返回标识 `deepseek-flash`；不推断服务端版本。三组共 180 次实际 HTTP 请求、271,996 token，缺 usage=0；另有上述 36 次连接失败。无已核实费率，货币费用为 null，不能拿 token 数冒充结算金额。

## 失败归因与采用决定

旧 Trace 的四类原因见 [diagnosis.md](diagnosis.md)。本次继续区分：

1. **检索遗漏**：同义地点案例初始 Hashing 没找到玩家事件；局部条件两边首次召回均 6/9，候选对应三次仍答不出，不能算表达退化。完整路径工具把地点补回，两边全回合证据取得均 9/9。
2. **上下文丢失**：完整基线 `denied_move_and_recall` 三次已经取得青苔，行动后表达却编出小雨点儿、黑旧伞、蓝雀。候选保留原玩家来源，三次均回述青苔。
3. **角色回避**：开发笔记问题的计划主动认为承认记住也有风险；不能只靠重新检索解决。候选不给表达模型传私密回避计划，要求允许范围内的普通问题先答清楚，这是一项行为取舍，未声称完整 persona 改善。
4. **证据使用错误**：完整基线地点答对却加“老陈/桥底”；候选仍会加“没去过那里”“玛尔塔婶”，或把缺少输入变成“不知道”。输入过滤消除了直接私密来源，不保证生成完全有据。
5. **披露绕过**：完整基线 `private_witness_baseline_r3` 用关系调整行动后透露儿子受威胁；`denied_reveal_baseline_r3` 不报名字也透露生命危险的私有认知。关系调整获准不等于私密内容获准。局部绳套同义披露还有正则漏检，全部经助手复核计入。
6. **未完成**：基线 private_witness r1、候选 r2/r3 的规划及一次重解析均 `finish_reason=length`（600 输出 token 上限）；未进入最终表达，记录 missing，没有扩预算补跑。失败调用保留了请求/工具返回及截断内容；Harness 抛错前没有返回完整 Trace/后状态快照，因此这些字段缺失，不能报状态通过。
7. **拒绝覆盖不足**：局部两类 fixed_action 确由 Manager 拒绝，每条件 6/6，候选仍回答独立普通问题且不声称动作成功。完整路径不强塞动作，指定六个请求两边均改成关系调整，实际指定拒绝覆盖 0/6。基线在另一个目击案例提出未知 fact 并被拒一次，候选无真实拒绝完成回合。局部拒绝测试不能冒充完整 Agent 拒绝验收。

**决定：不推广。** 尽管回答正确性和观测披露都有改善，候选未满足全部留出完成和关键路径覆盖要求，事实依据也仍有问题。保留可复现、默认关闭的候选及来源字段支持。下一次若根据这些留出失败调整候选，必须使用新的留出数据；本轮不增加工具决策、剧情、UI 或其他平台范围。

## 验证与复现

新增边界/评测契约覆盖来源保存恢复、旧存档保守处理、跨玩家/跨 NPC、工具伪造/失败/删除、partial/条件解锁、无行动/批准/拒绝/已结算路径及标签隔离。新增 14 项已通过，相关 Ruff 检查通过，现有前端 8 项通过。

全仓库本机 Qwen 条件运行 938 项：933 通过、2 跳过、3 失败，证据 [pytest.xml](pytest.xml)。失败为既有 `SceneOption.final_report` 与旧断言不一致，以及两个 shutdown 测试在创建会话时加载/编码 Qwen 超过 HTTP 默认五秒；本轮未改 scene 字段及相关断言。此前未指定本地模型的全套尝试中断，不计通过。相关路径使用显式 Hashing 补充运行 **144 通过、2 跳过**，包括原先超时的两个 shutdown 测试，结果另存 [pytest-focused.xml](pytest-focused.xml)，不覆盖原失败。

三个阶段候选运行源码哈希一致；180 个真实请求未含评分标签字段，保存的文本未检出实际配置凭据。离线复算与 `summary.json` 完全相等，核对记录见 [verification.json](verification.json)。Windows CRLF 以 `core.whitespace=cr-at-eol` 检查通过；未重写既有文件换行来清理与本轮无关的差异。

命令见 [commands.md](commands.md)。候选运行源码哈希冻结在各报告；新报告目录必须不存在。没有提交或推送。
